## Penilaian Kerusakan Data Masa Lalu (Damage Assessment — O-09)

- **Temuan Data Rusak:**
  - `user_progress`, `user_xp_log`, & `achievements`: Karena reward XP mini-game belum pernah diintegrasikan ke usecase database pada binary aktif, belum ada data XP/achievement korup yang tertulis di database (tabel masih bersih/kosong).
  - `users` & `session_participants`: Potensi ketidakcocokan format `users.id` (`usr-<discordID>` vs `<discordID>`) dapat meninggalkan baris user dengan `username` berupa angka ID Discord apabila user bermain game sebelum menjalankan `/radovid settings` atau `/radovid progress`.
- **Status Tindakan:**
  - Memerlukan standardisasi resolusi User ID di `SessionRepository` dan `UserRepository` serta penyambungan use case progresi di `GameHandler`.

## Daftar Pengujian yang Belum Dilakukan (Untested List — O-16)

*Deklarasikan secara eksplisit aspek yang sengaja belum/tidak diuji beserta alasannya:*
- **Interaksi Komponen Discord Live:** Pengujian tombol Discord secara live di server Discord sungguhan belum dilakukan karena bot token lingkungan produksi tidak dihubungkan dalam sandbox pengujian lokal (menggunakan simulasi mock interactions).
- **Stress-Test Konkurensi Ekstrem pada Ollama LLM:** Uji beban 10.000 concurrent LLM requests belum dijalankan karena keterbatasan kapasitas vRAM hardware lokal.
- **Transisi Daylight Saving Time (DST) di Level Host:** Pengujian pergeseran zona waktu musiman DST belum dilakukan karena server dan konfigurasi aplikasi berjalan pada zona waktu UTC dan WIB (UTC+7) yang tidak menerapkan DST.
